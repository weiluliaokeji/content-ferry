# Wayfinder #32：权限矩阵与自动放行/询问/拒绝规则

## 决策结论

ContentFerry 使用“硬性不变量 > 显式拒绝 > 显式授权 > 默认风险规则”的判定顺序。模型提供的风险标签和工具记忆只能帮助解释与排序，不能改变最终决定。

默认工具执行模式为“协作模式”：在授权租约和安全包络内的低风险只读调用自动连续执行；只有越过目标、网络、数据敏感性、执行副作用或时间/资源边界时才暂停询问。谨慎模式可以扩大询问范围；自动模式只能减少已明确授权隔离范围内的询问，不能覆盖硬拒绝或扩大授权。

## 判定顺序

一次调用必须先被规范化，再按以下顺序判定：

1. **协议与工具校验**：工具存在、输入符合 schema、参数数量/长度有界、调用依赖合法、目标可解析。失败即 `deny`/`failed`，不进入 Adapter。
2. **硬性安全不变量**：敏感凭据与浏览器配置目录、符号链接/junction 越界、危险 URL、任意 shell 文本、越过应用安全边界的请求不能通过普通授权租约放行。
3. **显式拒绝**：任何匹配的 `deny` 都优先于任何 `allow`，包括更窄的单次/项目拒绝覆盖更宽的全局允许。拒绝不会被自动模式、工具记忆或模型理由覆盖。
4. **显式授权**：匹配的有效 `allow` 租约满足工具、动作、项目、规范化目标、网络主机、执行目标和副作用约束时放行。
5. **默认风险规则**：没有显式授权时，仅允许列入默认低风险集合的调用自动放行；其余返回 `ask`。

默认风险规则永远不能把“没有匹配授权”解释成无限制允许。`ask` 是安全的未知状态，`deny` 是不可覆盖的策略结果。

## 默认矩阵（协作模式）

| 动作 | 目标与附加条件 | 默认风险 | 决定 | 说明 |
| --- | --- | --- | --- | --- |
| `read` | 当前项目授权目录内；非敏感；无符号链接/junction 越界；读取大小和文件数有界 | low | 自动放行 | 典型场景：读取文章、源码、配置模板和工具版本信息 |
| `network_read` | 已配置的公开主机/技能允许的来源；不含凭据；响应大小和时间有界 | low | 自动放行 | 新主机、重定向到新主机或下载可执行内容时重新判定 |
| `read` | 同一授权目录和同一只读包络，但换用 WSL/Docker/Sandbox 目标 | low/medium | 自动放行 | 目标切换是新调用，但只要范围没有扩大即可连续执行 |
| `read` / `network_read` | 新目录、新主机、新网络策略、跨项目或超出当前租约 | medium | 询问 | 询问中展示新增范围和原因 |
| 沙箱内代码执行 | 结构化 argv；只读挂载或明确的临时输出目录；网络关闭；有 CPU、内存、进程数、超时和输出上限 | medium | 首次配置询问；已有同类租约可自动放行 | 不能把沙箱标签当成绝对安全证明 |
| 沙箱内代码执行 | 需要联网、安装依赖、写入授权目录或挂载新的主机目录 | medium/high | 询问 | 每个新增副作用单独进入策略计算 |
| `host_trusted` 代码执行 | 本机进程、网络隔离无法强制、可影响宿主机 | high | 默认询问 | 只有用户明确授予同类主机执行租约后才可自动连续执行 |
| `sensitive_read` | 凭据、Cookie、SSH、云凭据、浏览器用户数据等 | high | 默认拒绝或按显式策略拒绝 | 工具记忆不能授权；如确有产品场景必须另设受限、可审计入口 |
| `write` | 项目授权目录内的临时产物或工具输出 | medium | 询问 | 需要说明路径、写入目的和预计产物；已有精确写入租约可放行 |
| `write` | 正式文章正文、资料卡、权限配置或执行记录 | high | 由对应内容/配置模块单独确认 | 工具租约不能自动代替正文应用或策略配置确认 |
| `delete` / `install` | 任意目标 | high | 询问 | 删除和安装不因“只是调研”而自动放行 |
| `external_write` / `publish` | 外部平台、远程仓库、消息或发布渠道 | high | 询问 | 必须保留最终用户操作或明确发布授权；不属于普通调研租约 |

这张表规定的是无显式租约时的默认行为。显式 `deny` 始终拒绝；显式 `allow` 也必须满足硬性不变量和输入校验，不能授权应用根目录、敏感目录、任意 shell 或不受控外部副作用。

## 授权租约

授权提示提供四种用户选择：

- **仅此次调用**：只覆盖当前 `callId`，执行结束立即失效。
- **本次任务同类调用**：覆盖当前 `workflowId` 内相同工具、动作、目标包络和副作用等级的调用。
- **当前项目同类调用**：覆盖当前 `projectId` 内相同工具、动作、目标包络和副作用等级的调用，并设置过期时间。
- **拒绝**：创建当前工作流的拒绝约束；原调用不执行，等价绕过也不执行。

全局租约只在“权限与工具”高级设置中显式创建，不作为普通授权卡片的默认选项。高风险动作的全局租约需要清晰展示影响范围和撤销入口。

租约至少匹配以下维度：

```text
toolId
action
projectId / workflowId / callId
canonical target or target prefix
network host set and network policy
execution target type
side-effect profile
expiry / revocation version
```

租约只能缩小到具体目标，不能被模型或调用方动态扩大。例如允许 `D:\work\article` 不能自动覆盖 `D:\work`；允许 `api.example.com` 不能覆盖 `example.com.evil`；允许 WSL 只读检查不能自动转成宿主机写入。

## 执行目标规则

本机、WSL、Docker 和 Windows Sandbox 都是策略输入中的 `executionTarget`。目标切换按以下步骤执行：

1. 适配器把请求转换为规范化目标、目录挂载、网络策略和副作用包络。
2. 权限引擎以新目标重新计算，不复用原目标的 `allow` 结果。
3. 如果目录、网络、进程权限和副作用均未扩大，可沿用同一低风险租约自动放行。
4. 如果目标不可用，不能静默回退到更高风险目标；阿文可以提出一个新的替代调用，新的调用重新走同一矩阵。
5. 目标切换、原因和前后包络写入执行活动与审计事件。

因此，本机切到 WSL 查看同一授权目录中的文件是否存在可以自动执行；Sandbox 切到本机执行代码、从禁网切到联网、从只读切到写入，均属于跨越授权边界，必须询问或被拒绝。

## 模式差异

| 模式 | 自动放行 | 询问扩大范围 | 不能改变 |
| --- | --- | --- | --- |
| 协作（默认） | 低风险读、已授权同类调用、同范围安全目标切换 | 新目标/新主机/新副作用/中高风险 | deny、硬性不变量、最终发布决定 |
| 谨慎 | 仅明确租约内的低风险读；中风险也询问 | 几乎所有新增执行或写入 | deny、硬性不变量 |
| 自动 | 用户明确选择的隔离工作区、工具组和时间范围内减少重复询问 | 越出隔离范围或出现高风险副作用 | deny、硬性不变量、外部发布确认 |

模式只是 `ask` 的收敛策略，不是额外授权层。切换模式不会扩大已有租约，也不会解除拒绝约束。

## 记录与错误语义

每次判定记录规范化后的工具、动作、目标、执行目标、网络策略、风险、匹配租约、最终决定和原因；不记录凭据、授权头或完整敏感内容。模型返回的风险标签单独保存为 `modelRiskHint`，不能冒充应用决定。

- `allow`：可以进入 Adapter；同一工作流内可以继续调度其他独立调用。
- `ask`：不调用 Adapter，生成待授权事件；用户授权后只恢复该调用和满足依赖的下游。
- `deny`：不调用 Adapter，记录拒绝约束；编排器可以要求模型重规划，不得把整个任务无条件标为成功或失败。
- `failed`：输入校验、工具不可用、执行目标不可用或 Adapter 失败；可向模型提供受限错误摘要并重规划，达到预算后可恢复失败。

## 对现有实现的影响

当前 `permission-policy.ts` 已具备 `allow/ask/deny` 和作用域匹配的基础，但需要在后续实现票据中补齐：

- 将执行目标、网络策略、副作用包络纳入匹配维度；
- 把默认自动放行限制为规范化、非敏感、边界内的低风险调用；
- 让显式拒绝和硬性不变量在所有 Adapter 前统一生效；
- 用租约/工作流上下文取代每次执行都必须填写的 `confirmed` 硬闸门；
- 为授权请求、拒绝约束和模式切换提供可审计事件。

这些是实现工作，不在本决策中直接改变当前生产执行接口。
