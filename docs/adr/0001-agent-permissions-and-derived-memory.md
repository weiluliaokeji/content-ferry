# 阿文采用分层权限与可重建记忆

阿文可以在用户已授权的项目、目录、执行环境和网络范围内自主选择工具并执行低风险任务，但权限由策略引擎而不是模型决定；高风险操作必须单次确认，工具记忆不能扩大工具授权。记忆以追加式原始事件为事实底稿，长期记忆作为带来源、可失效、可重建的派生层，通过异步提炼、巩固、压缩、合并和遗忘维护；这样既能让阿文持续学习写作规范和工具经验，又不会把一次性对话、模型推断或历史授权误当成永久规则。

## Consequences

- 需要分别维护原始事件、候选记忆、长期记忆、工具注册和权限授权的边界。
- 记忆检索必须显示作用域和来源，生成结果需要记录实际使用的记忆。
- 工具、目录、网络和依赖安装权限可以逐级扩大，但不能静默回退或由历史记忆自动扩大。
- 记忆维护是后台可恢复任务，不能阻塞文章编辑和生成；删除和重建派生记忆不能修改正式文章内容。
