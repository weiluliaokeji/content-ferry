# 联网调研以覆盖度而非资料卡数量完成

联网调研把用户指定资料作为必须保留处理结果的输入，并以独立论证价值组织证据卡：同质来源可聚合，不同证据性质分别保留。调研以待证问题的覆盖和未解决的时效/冲突风险作为完成条件，而非固定资料卡数；执行请求和时间预算只限制成本，耗尽时必须如实交付部分结果与缺口，供用户继续补研。

应用统一控制指定资料抓取、时效与覆盖检查、预算和完成判断；包括 Codex 内置搜索在内的模型能力只作为检索或整理执行者，不能绕过该闭环直接宣布完成。证据卡须保留主张到具体 URL 的归属；指定资料抓取失败时以待人工核验状态保留，部分调研经用户确认可继续创作但不得掩盖缺口。

研究计划按选题动态决定证据维度，系统以可解释的来源质量理由而非总分辅助取舍；冲突证据需显式保留。调研深度仅约束执行预算；后续刷新优先重核易变主张，并保留历史材料和用户选择。

搜索摘要只用于发现页面，证据候选必须来自正文抓取、可见浏览器核验或用户补录。研究计划和进度可见但不设前置审批门；创作只接收用户选定证据的主张与归属，公开引用由作者选择。每次抓取保存最小证据快照，应用根据结构化覆盖状态而非模型自述判断调研结果。

用户可以采纳、拒绝、待核验、拆分或合并证据候选，人工判断不被后续刷新静默推翻；AI 推荐与证据采纳分离。每次初始、继续或刷新调研均保留独立运行记录，当前推荐的更新不覆盖历史结论、快照或用户选择。

## Considered Options

- 固定少量资料卡：实现简单，但会过早压缩证据多样性并可能遗漏指定资料。
- 无边界地持续检索：覆盖更广，但成本、时延和可恢复性不可控。
