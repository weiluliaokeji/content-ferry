# Triage 标签

技能使用以下五个标准角色；右侧是本仓库实际使用的 GitHub label。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给无需持续人工操作的 Agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不处理或不再安排 |

技能提到标准角色时，使用对应的本仓库标签，不要另建同义标签。
