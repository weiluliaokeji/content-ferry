# 文渡（ContentFerry）用户使用说明

> 适用版本：0.1.x 开发预览版
> 最后更新：2026-08-24

文渡是一款运行在 Windows 本机的 AI 自媒体工作台。它帮助你从主题和资料开始创作文章，在本地 VitePress 文章库中编辑和保存，通过 AIGC 特征检测与人工预览后发布到微信公众号。

这份文档既是完整使用说明，也是后续生成网页帮助和 PDF 手册的源文件。界面仍在开发，个别按钮名称可能略有变化。

## 1. 开始前准备

第一次开始使用时，只需要：

- 一台 Windows 10/11 电脑。

首次启动向导会引导你选择数据目录和 AI 服务；进入应用后，再到"归档库"选择本地文章库。

需要发布到微信公众号时，再按本说明第 5～8 节依次添加账号、获取 AppID/AppSecret、配置 IP 白名单和回调地址。只体验本地创作时，可以暂不连接微信公众号。

## 2. 首次启动

安装版直接运行“文渡”。首次启动向导会引导你：

1. 选择数据目录；
2. 初始化 AI 服务；
3. 检查基础环境；
4. 完成设置并重启应用。

普通用户不需要安装 Node.js、Codex CLI、Docker、WSL 或 Hermes Agent。选择 OpenAI Codex 时，安装包会携带所需的内部运行组件；ChatGPT OAuth 登录用于取得模型授权。

### 数据保存在哪里

- 文章正文和文章图片：保存在你选择的 VitePress 文章库。
- 账号配置、发布记录、AI 会话、记忆摘要和运行日志：保存在首次启动时选择的文渡数据目录。
- AppSecret、API Key 和 OAuth 凭据：使用 Windows 安全存储保护，不以明文显示或写入日志。

建议把文章库和数据目录纳入自己的备份方案。不要把登录 Cookie 复制到其他电脑，恢复后重新登录更安全。

## 3. 配置 AI 服务

进入“技能与模型”，先配置一个文本模型。模型连接决定由谁执行，技能决定如何执行，两者不是同一件事。

### OpenAI Codex

1. 选择 OpenAI Codex。
2. 点击“使用 ChatGPT OAuth 授权”。
3. 在打开的授权页面完成登录。
4. 返回文渡，等待状态变为可用。

它不要求用户另行安装 Codex 软件，也不依赖 Hermes Agent。

Codex 连接编辑里有一个“联网补研使用 Codex 内置搜索”开关（默认开）：开启时，补研由 Codex SDK 直接联网检索并综合资料卡，开箱即用、原生检索质量更好；关闭时，补研改用应用的 Tavily / DuckDuckGo 检索链（资料 URL 由系统真实抓取、可追溯，且走“联网检索服务”里的全局检索代理）。如果你处于需要代理才能访问外网的防火墙环境、或特别看重来源 URL 可追溯，可把该开关关掉。

### 其他模型

除预置的 OpenAI Codex 外，文渡支持添加任意 **OpenAI 兼容端点**作为自定义连接：在“技能与模型”填写显示名称、模型名、服务地址（baseUrl）、访问凭证与（可选的）代理地址，即可接入 OpenAI API、OpenRouter、Nous Research、NVIDIA Build、GitHub Copilot 等任意兼容服务。不同提供商所需字段不同（有的要 API Key，有的要模型名或专属服务地址），凭据只加密保存在本机、不会回显或写入日志。每个连接的“代理地址”只影响该连接本身；留空就是直连，文章联网调研也不会借用其他模型连接的代理。

图片模型与文本模型分开配置。封面提示词技能负责分析文章并生成提示词，图片模型只接收用户最终确认的提示词；除非提示词明确要求，否则不应生成标题文字。

### 联网检索（可选）

在“技能与模型”页面的“联网检索服务”中可配置 Tavily。它不是大模型，也不需要分配给某一项技能；阿文在补充公开资料时会优先使用它。点击“配置”后填写 Tavily API Key，可先“测试连接”再保存。Key 加密保存在本机、不会回显或写入运行日志；移除后会恢复使用 Bing RSS 和 DuckDuckGo 等免配置搜索源。

当公开搜索页要求登录或人机验证时，文渡会打开“联网检索协助”窗口并保留该站点会话。请在窗口中自行完成网站要求的操作，再回到资料窗口点击“完成验证后重试”。文渡不会代替用户解验证码或绕过网站验证。

若你的网络需要通过代理才能访问 DuckDuckGo、Bing 等公开搜索源，可在“联网检索服务”中设置“检索代理”（例如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`）。该代理**只用于联网检索**，与“其他模型”里各连接的代理相互独立、互不影响；留空则检索直连。地址须以 `http://`、`https://` 或 `socks5://` 开头，填写无效时会自动忽略并回退直连，不会因此报错中断检索。

## 4. 配置 VitePress 文章库

进入"归档库"，选择 VitePress 的 `docs` 目录，而不是只选择 `docs/posts`。

例如：

```text
D:\Workbench\weiluliaokejiBlogs\docs
```

选择 `docs` 后，文渡才能同时识别站点结构、文章目录、Front Matter、图片路径和排序规则。扫描时会排除 `index.md`、排序说明等站点页面，保留真正的文章。

文渡以 VitePress Markdown 文件为正式正文来源：

- 新建草稿会直接写入文章库；
- 从文章库扫描出来的文章可以继续编辑和发布；
- 可以同时使用 Obsidian 或其他 Markdown 工具编辑；
- 标题、日期、`publish`、`tags` 等现有 Front Matter 字段应被保留；
- 图片通常保存在文章目录的 `assets` 中。

外部工具修改文件后，回到文渡重新扫描或打开文章，以磁盘上的最新内容为准。

## 5. 添加微信公众号账号

进入“账号”，添加平台为“微信公众号”的账号。账号名称只是文渡中的显示名称，可以与公众号名称一致，也可以使用便于区分的备注。

建议先填写账号定位：

- 账号定位；
- 目标读者；
- 禁用话题；
- 写作风格；
- 常用栏目。

如果账号已经有历史文章，后续可由 AI 提炼这些信息，再由用户确认。

## 6. 获取微信公众号 AppID 和 AppSecret

后台菜单可能随版本调整。当前常见路径如下：

1. 打开 [微信开发者平台](https://developers.weixin.qq.com/platform) 并登录。
2. 点击页面左上角“我的业务与服务”。
3. 选择“公众号”。
4. 在“基础信息”区域查看 AppID。
5. 按后台要求完成管理员验证后生成或重置 AppSecret。
6. 立即把 AppSecret 保存到密码管理器，再填入文渡。

AppSecret 通常只在生成或重置时完整显示。重置后，使用旧 AppSecret 的程序会失效；修改后应在文渡中重新“保存并测试连接”。

### 在文渡中保存并测试

1. 在“账号”找到目标公众号。
2. 点击“连接微信”或“编辑凭证”。
3. 填入 AppID、AppSecret 和回调 Token。
4. 点击“保存并测试连接”。

文渡会向微信申请一次 `access_token`，用来同时验证 AppID、AppSecret、网络连通性和 IP 白名单。测试失败时窗口不应静默关闭，应显示微信返回的错误原因。

## 7. 配置 IP 白名单

微信公众号 API 只接受白名单内公网 IP 发起的请求。家庭宽带或动态网络的出口 IP 变化后，需要重新更新。

常见操作路径同上面AppID、AppSecret 获取操作的步骤

填写的是公网出口 IP，不是 `127.0.0.1`，也不是通常以 `192.168.*`、`10.*` 开头的局域网地址。如果使用代理、公司网络、云函数或隧道，请确认微信实际看到的出口 IP。

## 8. 配置微信回调

微信接口返回“任务提交成功”并不等于文章最终发布成功。原创声明失败、平台审核或其他原因仍可能导致失败，因此文渡需要通过回调接收最终结果。

文渡本地回调路径为：

```text
/wechat/callback/<账号 ID>
```

本地服务监听 `127.0.0.1:4317`，微信公众号无法直接访问本机地址。需要使用可公网访问的 HTTPS 地址，将请求安全转发到这一本地路径。常见配置位置同上面AppID、AppSecret 获取操作的步骤，为“基本信息” → “域名与消息推送配置”。

配置时注意：

- URL 使用公网 HTTPS 地址，不能填写 `127.0.0.1`；
- Token 必须与文渡中该账号填写的回调 Token 一致；
- 当前明文模式只适合已确认的开发阶段能力；启用其他加密模式前应核对实现状态；
- 不要把 EncodingAESKey 误填到 Token 输入框；
- 公网转发只开放必要的回调路径，不要把整个本地服务暴露到互联网。


## 9. 从主题开始创作

在工作台点击“新建文章”，可在同一个窗口一次输入：

- 一个主题；
- 一个可选标题（也可以稍后由阿文推荐）；
- 自己的观点或零散想法；
- 已有资料、链接和需要保留的事实；
- 文章希望解决的问题。

“创作主题或想法”可直接粘贴较长的构思和资料（最多 12000 字符），它决定文章讨论什么；“写作目标”描述希望读者得到什么，两者不应混用。主题是唯一必填项；不填写写作目标时，阿文会在补研和提纲阶段结合主题与账号定位补足方向。如果没有填写标题且输入较长，文渡会先创建一个临时草稿标题；后续可在“编辑创作方向”中让阿文推荐或自行修改正式标题。

如果当前只绑定了一个账号，文渡会默认选中它；绑定多个账号时需要自行选择，仍可暂不选择。

账号定位与主题一致时，AI 不会重复询问账号已经保存的信息。只有文章明显偏离定位，或缺少会影响事实与核心角度的必要信息时，才会补问。

推荐流程：

1. 整理创作简报；
2. 阿文默认联网补充资料，优先检索官方文档与原始资料；
3. 查看研究结论和资料卡，取消勾选不希望用于写作的来源；
4. AI 基于已选资料形成提纲，用户确认或修改；
5. AI 起草正文；
6. 在编辑器中继续修改；

点击“创建并联网补研”后，文渡会一次创建 VitePress 草稿、内容项目和创作简报，再直接进入联网资料窗口。之后如需调整创作主题或想法、目标、读者、角度、资料或标题，可在工作台选择“编辑创作方向”。创作主题会作为后续补研、提纲和标题推荐的上下文，和正式文章标题分开保存；保存修改后的标题才会同步更新 VitePress 文件和文章目录。简报保存后不会覆盖已经确认的提纲版本。

阿文一次最多推荐三个标题，会直接使用当前尚未保存的简报内容；如果本地文章库中存在可识别的系列标题，例如“零成本基建系列——”，会显示本次用于推荐的历史系列。文渡只会在当前方向相关时建议延续该系列，最终标题始终由你决定。

如果生成提纲时出现“本地连接被中断”，通常表示文渡正在重启或开发环境刚重新编译完成。等待窗口稳定后重新点击“生成提纲”即可；已经流式显示的内容会保留在窗口中，可继续编辑后保存。

阿文推荐的标题只是候选，不会自动替换当前标题。点击某一候选标题（或自行修改标题）后再保存简报，文渡才会同步更新文章的 Front Matter、一级标题和对应目录。

保存创作简报后，点击“联网补研”。阿文会生成研究结论和资料卡；资料卡显示直接来源链接、摘要、关键主张和获取时间。当“研究”技能指派给 Codex 且其“内置搜索”开关打开（默认）时，检索由 Codex SDK 直接完成；其余情况由应用的 Tavily / DuckDuckGo 检索链完成（来源 URL 由系统真实抓取）。默认勾选的资料会传给提纲和正文生成；取消勾选后不会使用。对需要登录、验证码或复杂网页交互的来源，当前版本不会伪造结果，应由你自行核对。

如果资料还不够，在“第三步：补充资料”底部的“继续补研”中直接告诉阿文还要查什么，例如“核查当前调用限额，只使用官方文档”或“补充不适用场景和反例”。原有资料不会被覆盖，新结论和不重复的新资料会追加；这轮要求与结论也会保存在本文的“与阿文对话”记录中，之后编辑正文时可以回看。

确认提纲后，工作台仍会提供“编辑提纲”。提纲只展示文章的章节、判断和论证角度，不应混入检索任务、待核查清单或给作者的写作指令。生成提纲和起草正文都会保留你已经确认的文章标题；AI 只负责内容，不会借由一级标题重命名文章或目录。

在所见即所得编辑器中选中提纲或正文后，可按 `Ctrl+C` 复制选中的文字；`Ctrl+Z` 和 `Ctrl+Y` 可撤销或重做编辑操作。

从网页复制单个图片、截图工具复制的 PNG/JPEG/GIF/WebP 图片时，直接粘贴到所见即所得编辑器即可。文渡会保存到当前文章的 `assets/` 目录，并插入本地引用；同样支持粘贴形如 `![说明](https://example.com/image.png)` 的单个远程 Markdown 图片。若图片地址不可访问、不是受支持格式、超过 15 MB 或指向本机/私有网络，文渡会提示原因且不会写入该远程引用。
6. 完成封面、摘要和 AIGC 特征检测；
7. 创建微信草稿并人工预览；

代码块会在同步微信草稿时保留缩进和换行。若微信后台预览仍出现异常，应先不要正式发布，并在运行日志中记录对应文章与草稿时间以便排查。
8. 普通发布或群发。

AI 输出可能出错。重要事实、数据、引用、版本号和操作步骤仍应由作者确认。

### 回看文章的创作过程

文章发布完成并归档后，创作过程不会丢失。在「归档库」点击文章右侧的 ⋯ 展开操作区，除「重新发布」外，还会按这篇文章实际留下的记录显示「查看创作方向」「查看素材」「查看提纲」，可随时回看当时的创作简报、联网资料卡和提纲。同一时刻只会展开一行，点击其他文章的 ⋯ 会自动收起上一行。

不是通过文渡创建的文章（例如你用其他编辑器直接写进文章库的）没有这些记录，展开后只会显示「重新发布」。

未归档的文章在「工作台」同样可以查看：生成提纲或正文后，「编辑创作方向」会变为「查看创作方向」，查看不会覆盖已确认的内容。

## 10. 编辑文章

编辑器支持“所见即所得”和“Markdown 原文”两种模式。切换模式时会尽量保持顶部可见内容一致。

常用操作：

- `Ctrl+S`：保存；
- `Ctrl+Z`：撤销；
- `Ctrl+Y`：重做；
- 拖入、粘贴或选择本地图片；
- 插入标题、列表、任务列表、链接、引用、代码和表格；
- 点击文章结构中的标题跳转到对应段落；
- 手机预览微信公众号中的大致阅读效果。

离开存在未保存修改的文章时，文渡应提示保存或放弃，避免内容丢失。

## 11. 使用阿文和选区 AI

“阿文”是文章顾问。它以当前文章、当前文章的历史会话和提炼后的写作记忆为上下文，可以讨论选题、结构、表达、读者理解成本和发布准备。

选中正文后可使用：

- 去 AI 味；
- 改写；
- 扩写；
- 缩写；
- 补充案例；
- AIGC 特征检测。

未选中文字时，AIGC 特征检测会检测当前正文全文，按钮显示“检测全文内容”；选中一段文字后，按钮会改为“检测选中内容”，只将该段发送给腾讯朱雀或 ContentAny。只有全文检测结果会保存到本篇文章的质量记录；之后打开“准备发布”会直接显示已完成的检测，无需重复检测。选区检测仅用于局部优化，不会替代全文检测。

选择动作后，可以在“补充要求（可选）”中说明本次改写意图，例如“保留技术术语，语气更直接”或“面向非技术读者解释，不要营销化表达”。留空时使用技能默认规则；按 `Ctrl+Enter` 可直接生成替换建议。

AI 修改先以建议形式展示。建议卡会贴在对应正文段落之后，可拖动到更顺手的位置；切换编辑模式后仍会回到该段落。接受后直接更新正文，并可用 `Ctrl+Z` 撤销；拒绝不会修改文章。正文不会重复显示已处理或因手工修改而无法定位的建议，但阿文会话会保留完整建议内容、改写文本及“已接受”“已拒绝”或“无法定位”的处理记录。发送给阿文的消息会先显示“正在发送”；若模型或网络中断，消息会保留并标出失败，可在原消息旁点击“↻ 重新发送”，不会无提示消失。历史会话中最后一条没有阿文回复的用户消息，也会显示为可重发。重要、稳定且可复用的写作偏好会被摘要，而不是把整段会话直接当作长期记忆。

## 12. 技能与模型

技能决定任务规则，模型连接决定执行服务。

内置技能包括：

- 微信公众号文章撰写；
- 平台稿改写；
- 选区 AI 编辑；
- 文章选区去 AI 味；
- 文章摘要生成；
- 封面提示词生成；
- 文章封面生成；
- 腾讯朱雀 AI 检测；
- ContentAny AI 检测；
- 阿文文章顾问。

每个技能拥有独立 `SKILL.md`，部分技能还有 `references/`。修改技能会影响后续调用结果；不熟悉提示词和输出约束时，建议先备份再改。

同类技能默认按大模型类型分组（文本类、图像类、无模型）。要成批更换某类技能使用的模型连接：

1. 在分组标题右侧点「全选」，勾选该组下全部技能（或逐一点击技能卡片右上角的勾选框）；点「取消全选」可清空。
2. 在「选择目标模型…」下拉里挑一个已配置的模型连接。
3. 点「应用到选中的 N 个技能」，所选技能会一次性切换到该连接。

「全选 / 取消全选」仅出现在有模型连接的分组（文本类、图像类）；「无模型技能」走浏览器自动化，没有可切换的大模型。

## 13. 封面和摘要

封面可以来自：

- 本地图片；
- 文章中的图片；
- 微信素材库；
- AI 生成。

本地图片确认后会复制到文章对应素材目录。裁剪时通过可视矩形框选择区域，不需要填写微信 `media_id`。

使用 AI 生成封面时：

1. 先让“封面提示词生成”技能根据正文产生可编辑提示词；
2. 用户检查并修改提示词；
3. 图片模型只接收最终提示词；
4. 默认不生成标题、Logo、水印或二维码；
5. 只有提示词明确要求文字时才允许生成文字。

图片模型排队时间不固定。生成期间可继续编辑正文和文章设置；文渡会持续等待，直到图片服务明确成功或失败。若开启“AI 调用审计”，可在审计日志中查看本次图片任务的提交、轮询和下载响应摘要。

封面提示词属于文章发布设置：点击“保存发布设置”后会与封面、摘要和作者一起保存；下次进入文章会自动带回。生成图片期间仍可点击“保存文章”保存正文修改。

微信公众号摘要最多 120 字。摘要技能会根据平台限制提炼，不会简单截断正文。

## 14. AIGC 特征检测

腾讯朱雀和 ContentAny 都通过浏览器自动化运行，不需要大模型连接。

通常文渡会自动：

1. 打开检测网页；
2. 填入待检测内容；
3. 点击检测；
4. 等待结果；
5. 提取分段样式、比例或参考结论并回填。

只有登录、验证码、额度用尽或网页结构变化时才需要人工接管。检测结果是文章优化信号，不是事实判定。即使 AI 特征较高，用户仍可填写理由后例外发布。

## 15. 发布到微信公众号

微信公众号草稿是官方接口的必经步骤：

1. 文渡上传正文图片和封面；
2. 调用 `draft/add` 创建微信草稿；
3. 若文章设置中选择了“申请原创声明”“开启赞赏”或“加入合集”，在发布记录点击“在微信后台完善并发布”。文渡会打开可见浏览器，定位到对应草稿卡片并尝试悬停、点击卡片的“编辑”按钮；能可靠识别的选项会自动尝试设置；
4. 用户在微信后台人工预览，确认原创、赞赏、合集等设置并点击发布；
5. 或回到文渡选择普通发布或群发；
6. 等待微信最终回执。

“普通发布”和“群发”不同：

- 普通发布使用 `freepublish/submit`，适合获得永久链接等场景，不等于向所有关注者推送；
- 群发使用 `message/mass/sendall`，会消耗公众号群发额度；
- 接口 `errcode=0` 只表示任务提交成功，不表示最终发布成功。

原创、快捷转载、赞赏等能力是否能由接口直接设置，以微信当前开放能力为准。文章设置可保存“申请原创声明”“开启赞赏”和已有合集名称；创建草稿时这些设置会固定到该发布任务。需要网页处理时，在发布记录点击“在微信后台完善并发布”。处理合集时，文渡会从微信的“选择合集”窗口读取当前可见的名称，并按已选公众号缓存；下次编辑同一公众号的文章时可直接从下拉建议中选择，旁边会显示最近同步时间。缓存只用于方便选择，微信后台仍是最终来源；同名合集、页面变化或额外确认会保留给你处理，最后的预览和发布始终由你完成。申请原创声明与开启赞赏默认勾选，作者默认填入最近使用过的账号；从工作台点击微信公众号的“设置并发布”时，未设置过发布账号的文章会自动选中第一个已绑定的微信公众号账号，仍可自行切换；这些设置均可在文章设置中随时修改。

点击“微信草稿箱”后，如果尚未登录，先自行选择扫码或账号密码登录；文渡不会替你点击登录按钮或改变登录方式。登录成功后会自动进入“内容管理 → 草稿箱”，用于手机预览和处理微信后台设置。

如果回调未及时到达，但已经在微信后台确认最终结果，可以在发布记录人工校正为已发布、失败或取消发布，并填写简短原因。

## 16. CSDN 渠道稿（当前可用范围）

在"账号"添加 CSDN 账号后，进入"工作台"，在文章右侧点击"生成 CSDN 稿"（已归档文章先在"归档库"点 ⋯ 展开后点"重新发布"回到工作台）。生成方式默认是“直接使用主稿”；如需平台化改写，可手动改选 AI 改写。创建后会打开一个与主稿同款的独立工作台（顶栏 + 左侧工具 + 中间所见即所得编辑器 + 右侧手机预览/发布设置），只是发布渠道不同：

- 左侧工具：正文（字数/图片数/阅读时长）、文章结构（点击跳转到对应标题）、图片素材（列出正文图片）。
- 中间编辑器：与主稿完全相同的所见即所得编辑器，支持图片、列表、表格等；源稿图片（含 VitePress 源文章的相对路径图片）也能正常预览，新插入的图片独立存到该渠道稿的资产目录。
- 右侧面板有三个标签页：「AI 助手」「手机预览」「发布设置」。
  - **AI 助手**：选中正文后可让 AI 去 AI 味、改写、扩写、缩写或补充案例（先预览再「应用替换」，不会自动覆盖原文）；未选中时下达指令会对整篇生效。处理产生的对话会记录下来。
  - **手机预览**：按 CSDN 调性实时预览。
  - **发布设置**：填写作者、摘要与封面。摘要默认沿用主稿摘要，可点「AI 生成适配摘要」重写；封面默认沿用主稿封面，可「选择本地图片」上传，也可在「AI 生成封面」里选图片模型、让 AI 根据正文生成提示词再生成并设为封面。
- 编辑器工具栏同样提供「所见即所得 / Markdown 原文」切换：点击 `</>` 进入 Markdown 源码编辑，再点 `✎` 切回。冻结后的稿只读，不能切换或直接编辑。
- 工作台（未归档文章）每条文章下方按**渠道分行**展示分发状态，每行用平台图标 + 状态图标表示（鼠标悬停显示平台与状态文字），彻底区分主稿与渠道稿：状态如「未发布 / 草稿待发布 / 已发布 / 未生成 / 草稿 / 已冻结」，右侧按钮为「设置并发布 / 继续发布 / 进入 CSDN 稿 / 生成 CSDN 稿」等对应操作。未来新增渠道会自动追加一行，无需改动列表结构。
- 重进已生成的稿：CSDN 行显示「草稿 / 已冻结」状态，点“进入 CSDN 稿”直接打开工作台；若该文章存在多份渠道稿（不同账号），会先弹选择框让你挑一份或“新建渠道稿”。新建入口仍是“生成 CSDN 稿”。
- CSDN 稿与主稿、微信公众号稿互不覆盖；在草稿态点击顶栏「发布到 CSDN」即可一步完成：自动保存未存修改 → 冻结为内容快照（弹窗提示锁定后只能重新生成）→ 创建本地可恢复发布任务。已处于冻结（approved）态的稿直接创建任务，不再有独立的「审核并冻结」或「创建 CSDN 发布任务」按钮。不再需要的渠道稿可点「删除渠道稿」移除。
- CSDN 一期不允许公众号原文链接、正文引用、文末延伸阅读、二维码、评论区引流或其他软引流内容；发现这类内容时不能冻结。
- 冻结后任务不会立即向 CSDN 提交。随后在发布设置面板或「发布记录」的 CSDN 任务区，点击「在浏览器中完成发布」：文渡会打开按账号隔离、持久保留登录态的 CSDN 编辑器窗口，自动预检登录并填充标题与正文；填充完成后请在浏览器中核对摘要、标签与封面。确认无误后，在文渡点击「我已在 CSDN 发布」——文渡会点击 CSDN 的“发布文章”按钮并读回文章链接；读不到链接时安全降级为「待人工核对」，你可在 CSDN 后台核实后用「校正状态」标记。文渡不会绕过你的确认自动发布，也不会在回读不确定时谎报发布成功。
- 提示：CSDN 编辑器的页面结构以通用假设实现，首次使用建议观察浏览器窗口中的状态提示；若自动填充或回读不符合预期，可改为在浏览器中手动发布，再用「校正状态」记录结果。窗口仍打开时再点「重新打开 CSDN 后台」会直接把窗口提到前台并复用已填充内容，不会重复上传图片；只有关闭窗口后再打开才会重新填充。

## 17. 博客园渠道稿（当前可用范围）

博客园使用官方 MetaWeblog 接口（API Key 方式）直发文章，不需要浏览器自动化。

**第一步：添加博客园账号**

1. 登录博客园，进入「后台 → 设置 → 其它设置 → MetaWeblog 访问令牌」，复制你的 API Key（形如一串随机字符，与登录密码不同）。
2. 在文渡「账号」中点击添加，选择「博客园」，填写你的博客园用户名（形如 `weiluliaokeji`，即博客地址 `https://www.cnblogs.com/用户名` 中的用户名）和刚才复制的 API Key。
3. 保存后文渡会加密保存凭据，不会在界面回显；发布时凭据缺失或错误会进入「待补凭据」状态，可回到账号设置修正。

**第二步：生成并编辑博客园稿**

在「工作台」中打开一篇文章，点击右侧「生成博客园稿」（已归档文章先在「归档库」点 ⋯ 展开后点「重新发布」回到工作台），选择目标账号与生成方式（默认直接使用主稿，也可改选 AI 改写）。会打开与 CSDN 同款的独立工作台：左侧工具、中间所见即所得编辑器、右侧「AI 助手 / 手机预览 / 发布设置」三栏。编辑完成后点「保存渠道稿」，确认无误后点「审核并冻结」。与 CSDN 一样，博客园稿不允许公众号原文链接、文末延伸阅读等软引流内容。

在“发布设置”中，点击“读取博客园个人分类与 Tag”会打开博客园创作后台，并从该窗口当前登录账号读取“个人分类”和自定义 Tag 供选择；首次使用请先在打开的窗口登录。博客园没有公开的这两类列表接口，因此不会把 MetaWeblog 返回的网站分类误当成个人分类。两处都保留手工输入。

**第三步：两段式发布**

1. 冻结后点击「创建博客园发布任务」：文渡通过 MetaWeblog 调用 `newPost` 创建一个博客园草稿，并把正文中的本地图片上传到博客园图床、封面作为正文第一张图、自动加入 `[Markdown]` 分类。
2. 草稿创建成功后，任务状态显示「草稿待公开」并展示博客园草稿链接。你可以先点开链接检查标题、正文、图片与分类。
3. 确认无误后点击「确认公开」：文渡调用 `editPost` 把草稿公开，完成后展示正式文章链接，任务状态变为「已发布」。不确认则不会公开，重复点击也不会产生重复文章。

**第四步：异常与人工校正**

- 凭据缺失或错误：任务进入「待补凭据」，补齐账号 API Key 后可继续。
- 网络失败或公开失败：任务显示失败原因，可在网络恢复后重试。
- 结果不确定（如超时但博客园实际已发布）：任务进入「待人工核对」，你可在博客园后台核实后用「校正状态」把任务标记为已发布、失败或取消，避免重复发布。

## 21. 常见问题

### 为什么文章和数据库中的状态不一致？

正文以 VitePress 文件为准，数据库保存索引和工作流状态。外部修改、回调延迟或已删除文章对应的历史发布记录都可能造成短时差异。重新扫描文章库或在发布记录校正状态，不要直接编辑数据库。

### 为什么检测工具打开了浏览器？

腾讯朱雀和 ContentAny 没有可依赖的稳定官方接口，文渡需要操作网页并读取结果。可见浏览器便于登录、验证码和异常时接管；稳定后可再评估无头模式。

### 为什么微信显示“提交成功”但文章还没发布？

提交成功只表示微信接受了任务。最终状态要等待回调，或由用户在微信后台核实后人工校正。
