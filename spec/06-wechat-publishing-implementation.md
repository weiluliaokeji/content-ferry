# 微信公众号发布接口一期实现

## 已实现范围

一期采用“草稿优先、人工预览、明确选择发布方式、异步确认结果”的流程：

1. 在账号页加密保存 AppID、AppSecret 和消息校验 Token。
2. 使用 `stable_token` 获取并缓存 `access_token`，提前 5 分钟失效；并发请求共享同一次刷新。
3. 将正文中的本地图片上传到微信正文图片接口。
4. 封面必须由用户明确选择，不再自动使用正文第一张图片。可选来源包括：
   - 从电脑选择本地图片，确认后复制到当前 VitePress 文章的 `assets` 目录，或 ContentFerry 文章素材目录；
   - 使用 ModelScope 根据标题和正文生成封面，生成结果同样保存到文章素材目录；
   - 拉取所选公众号的永久图片素材库，以缩略图和名称供用户选择。
   微信接口仍需要 `thumb_media_id`，但这是系统内部字段，不要求普通用户手工查找或填写。
5. 调用 `draft/add` 创建微信草稿。
   - Markdown 围栏代码块转换为微信 HTML 时必须保留缩进与每一行换行：使用内联 `white-space: pre-wrap`，并将源换行转换为显式 `<br/>`。不得只依赖 HTML 文本节点中的换行符，因为微信草稿编辑器可能在保存时折叠它们。
6. 用户在微信后台完成手机预览。文章设置中的“申请原创声明”“开启赞赏”“加入合集”会随创建草稿时的发布任务保存；从发布记录点击“在微信后台完善并发布”后，可见浏览器会进入该草稿并在可确认的情况下尝试设置这些选项。处理合集时，浏览器先读取微信选择器中可见的未过滤名称，按公众号写入本地缓存，再筛选和选择文章预填的完整名称。
7. 用户回到 ContentFerry，明确选择：
   - `freepublish/submit`：普通发布，不向粉丝群发；
   - `message/mass/sendall`：群发所有关注者，会消耗群发额度。
8. 接口返回成功只记录为“已提交”，不显示为“发布成功”。
9. 微信明文回调通过签名验证后，按 `publish_id` 或 `msg_id` 更新最终状态。

发布记录中草稿任务的操作顺序固定为“在微信后台完善并发布 → 普通发布 → 群发所有关注者 → 已在微信后台处理”，四个按钮使用一致的中性操作样式。打开草稿箱后，文渡不自动点击或切换登录方式；用户完成扫码或账号密码登录后，浏览器自动继续导航“内容管理 → 草稿箱 → 唯一匹配的目标草稿卡片 → 悬停后点击卡片的编辑按钮”。对原创、赞赏和合集，浏览器只在已识别到控件且能确认状态时执行幂等操作；不确定、同名或页面变化时保留在该页面提示用户确认。文渡不会替用户点击最终“发布”。

## 回调地址

每个公众号使用独立路径：

```text
/wechat/callback/{accountId}
```

公网转发服务需要把微信公众号后台配置的开发者 URL 转发到该本地路径。当前一期支持已经验证过的明文模式；安全模式的消息解密不在本轮范围内。

ContentFerry 当前在本机固定监听 `127.0.0.1:4317`，因此完整的本地接收地址为：

```text
http://127.0.0.1:4317/wechat/callback/{accountId}
```

微信公众号服务器不能访问 `127.0.0.1`。公众号后台应填写公网可访问的 HTTPS 地址（通常为 443 端口），再由既有公网回调服务或安全隧道转发到上述本地地址。界面显示本地地址是为了说明 ContentFerry 的接收目标，不代表可以直接填入微信后台。

## 连接配置与测试

- 再次打开“连接微信”时会显示已有 AppID，并允许修改。
- AppSecret 和消息校验 Token 只显示“已配置”状态，不回传明文；留空表示保留原值，输入新值才会覆盖。
- “保存并测试连接”会调用微信 `stable_token` 接口申请 `access_token`，用于验证 AppID、AppSecret、网络连通性和当前出口 IP 白名单。
- 该测试不会创建草稿、不会发布或群发，也不会验证公网回调能否到达本机。素材库读取、草稿创建和回调接收分别在实际步骤中验证对应权限。

ModelScope Token 使用与账号凭证相同的本地加密存储，不会回显明文。

## 图片规则

- ContentFerry 新建文章中的本地图片会从本地素材库读取并上传。
- VitePress 文章支持相对文章目录的图片、`../` 路径，以及 VitePress `docs/public` 对应的根路径图片。
- 所有本地图片读取都会限制在已配置的 `docs` 根目录内。
- 远程图片链接暂时保留原地址；正式发布前应在微信草稿箱检查是否正常显示。

## 状态语义

- `draft_ready`：微信草稿已创建，等待人工预览。
- `submitted`：发布或群发任务已被微信受理，最终结果未知。
- `published`：已收到微信成功回调。
- `failed`：接口提交失败或微信回调确认失败。
